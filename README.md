# @zklogic/types-pako

TypeScript definitions for [pako](https://github.com/nodeca/pako),
forked from `@types/pako` and maintained by zklogic.

`@types/pako` upstream is a deprecated stub referencing pako's own
bundled types, but the resolved `pako` version in this project (2.1.0)
does not ship its own types, so this fork keeps a working copy.

## Installation
```
npm install --save-dev @zklogic/types-pako
```
